# Archived experimental grape Esca pilot

`grape-esca-pilot-v0.1.0.onnx` is retained only as a historical research artifact. It is not registered in the current model router, is not shipped to the app, and must not be enabled for diagnosis. Its narrow Esca-vs-Healthy label space produced false Esca-like alerts on other grape diseases in the external Grape Leaf Health probe. See `grape-esca-pilot-failure-report.json` and the GVLiD recovery/evaluation record under `research/training-results/2026-11-23/gvlid-recovery/`.

The GVLiD evaluation is an India-source, reconstructed vineyard split and is not Syrian coastal validation. The external probe contained no Esca-positive examples, so it cannot establish Esca sensitivity. Threshold values were exploratory/post-hoc and are not approved operating thresholds. This archive is preserved for reproducibility and comparison only.
