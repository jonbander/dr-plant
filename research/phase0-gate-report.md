# تقرير بوابة الجاهزية Phase 0 — Dr.Plant

**تاريخ الحالة:** 2026-11-27  
**الحالة العامة: NO-GO — البوابة مفتوحة**

هذا تقرير حالة أولي مبني على التدقيق الموجود في الفرع. لا يمثل إغلاقاً لأي بند لم تُجمع أدلته بعد.

## 1. تدقيق مجموعات البيانات — غير مغلق

- أُنشئ `research/data-audit.csv` للمرشحات السبعة المطلوبة، إضافة إلى ثلاث مجموعات سبق حظرها.
- كل المرشحات حالياً `NEEDS_REVIEW`؛ لا توجد موافقة نهائية دون رابط ومصدر وترخيص مؤرشف فعلياً وبصمة للأرشيف ونوع التعليق.
- هذا الوضع مقصود: لا نختلق SPDX أو URL أو نوع annotation أو field/lab status.
- لا يُسمح بالتدريب من أي سجل حتى يتحول إلى `APPROVED` أو `REJECTED` مع سبب ودليل.

## 2. Gold Masks — غير مغلق

- توجد حزمة مراجعة محلية من 24 صورة لعينة عنب، تشمل أقنعة leaf candidates آلية.
- لا يوجد تصدير مراجعة بشرية في المستودع وقت إعداد هذا التقرير؛ لذلك عدد الأقنعة الذهبية المقبولة = **0 مثبتة**.
- لا توجد حالياً مجموعة معتمدة موثقة للعنب أو الحمضيات أو البندورة.
- يجب تقييم leaf_mask وlesion_mask كل على حدة، وتوثيق المراجعين والمؤهلات وIoU وDice ودقة الحدود وتغطية الآفة والتطابق مع التسمية.
- لا يُستنتج من مراجعة المستخدم وحدها اعتماد خبير صحة نباتات.

## 3. الترخيص والتسميات والتقسيم — غير مغلق

- المجموعات المحظورة السابقة ESCA Mendeley V1 وCitrus Zenodo V1 وFieldVitis V2 أُدرجت في سجل التدقيق لإغلاقها رسمياً؛ لم يصدر بعد قرار نهائي REJECTED/APPROVED موثق لكل واحدة.
- `public/models/plant-disease/labels.json` كان فارغاً في التدقيق السابق. لم يُنشأ mapping تخميني؛ `research/label-map.json` لم يعتمد بعد.
- أُنشئ `research/split-protocol.md` ببروتوكولات العنب والحمضيات والبندورة، لكنه لا يغلق البند قبل تشغيل اختبارات عدم التسرب على manifests ذات group IDs حقيقية.

## قرار البوابة

**NO-GO.** لا يبدأ Phase 1 ولا التدريب الهجين. يستمر العمل على إغلاق Phase 0 فقط، مع السماح بأعمال التوثيق والتدقيق والاختبارات غير التدريبية.

## معايير الإغلاق

1. كل صف في `research/data-audit.csv` إما `APPROVED` مع ترخيص مؤرشف وبصمة واستخدام محدد، أو `REJECTED` مع سبب واضح؛ لا `NEEDS_REVIEW` عند الإغلاق.
2. تقرير Gold Masks يحدد العدد المقبول والجودة والقرار لكل محصول ولكل نوع قناع، مع مراجعة مؤهلة موثقة.
3. قرار نهائي لكل مجموعة محظورة، و`research/label-map.json` مكتمل بلا TBD، وبروتوكول split اجتاز فحوص التداخل والتشابه.
4. توقيع قرار GO في `research/decisions/DECISION_LOG.md` مع روابط الأدلة والاختبارات.
