# GVLiD Dataset

GVLiD: Grapevine Leaf Disease Dataset

Total Images: 3477
Classes: Black_Rot, Esca, Leaf_Blight, Healthy

## Description
Dataset for AI-based grape leaf disease detection.

## Usage
Use images folder and metadata.csv for ML tasks.

## Citation
Gayakwad M. et al. GVLiD Dataset.

The curated model's per-image vineyard-disjoint split was reconstructed from the archived training-summary assignments because the original ZIP contained only split counts and vineyard IDs. The deterministic reconstruction is saved as `split-manifest.csv`, with its method and counts in `results/gvlid-v5-clean-2class/split-reconstruction.json`. It reproduces the reported 953/195/175 counts but is not claimed to be the original training-time file.
