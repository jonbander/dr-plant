# سجل القرارات البحثية — Dr.Plant

> يسجل هذا الملف القرارات المعتمدة وأدلتها وآثارها. لا يُعد المقترح قراراً منفذاً ما لم يُذكر ذلك صراحة.

## D-2026-11-27-001 — اعتماد Phase 0 بوابة مانعة قبل التدريب الهجين

- **التاريخ:** 2026-11-27
- **الحالة:** معتمد من صاحب المشروع في المحادثة.
- **القرار:** اعتماد Phase 0 بوابة جاهزية إلزامية. لا يبدأ Phase 1 ولا التدريب الهجين قبل إغلاق بنود تدقيق البيانات، ومراجعة Gold Masks، والترخيص والتسميات والتقسيم المستقل.
- **الدليل:** موافقة صاحب المشروع على خطة Phase 0 ثم Phase 1–5؛ وتقرير `docs/MORPHOLOGY_V2_ASSET_READINESS_AUDIT-2026-11-27.md` الذي وثق فراغ disease labels، وعدم وجود تصدير Gold Mask بشري، ونواقص الأرشيفات/التراخيص، ومخاطر استقلال التقسيم.
- **الأثر:** يبقى التدريب الجديد متوقفاً. يستمر التدقيق والتوثيق والاختبارات غير التدريبية على فرع البحث فقط.

## D-2026-11-27-002 — موافقات البيانات مرتبطة بالمهمة لا باسم المجموعة فقط

- **التاريخ:** 2026-11-27
- **الحالة:** معتمد ضمن تنقيح الخطة.
- **القرار:** تسجل الموافقة لكل استخدام محدد (تصنيف مرض، تحديد موضع، تجزئة، شكل/صنف)، مع SPDX ودليل الترخيص المؤرشف. لا تعني الموافقة على تصنيف الصور الموافقة على تدريب تجزئة الآفات.
- **الدليل:** اختلاف أنواع التعليقات بين image-level وbbox وpixel masks، واختلاف صلاحية البيانات بحسب المهمة.
- **الأثر:** يضاف حقل task_scope وannotation_type إلى تدقيق البيانات؛ أي استخدام غير مثبت يبقى غير معتمد.

## D-2026-11-27-003 — فصل أقنعة الورقة عن أقنعة الآفة

- **التاريخ:** 2026-11-27
- **الحالة:** معتمد ضمن تنقيح الخطة.
- **القرار:** اعتماد نوعين مستقلين: `leaf_mask` و`lesion_mask`. لا تُستخدم أقنعة الورقة كمرجع لتجزئة الآفة.
- **الدليل:** لكل قناع هدف وحدود ومعيار تقييم مختلف.
- **الأثر:** تقارير Gold Masks وقياسات الجودة وقرار الكفاية تصدر لكل محصول ولكل نوع قناع على حدة.

## D-2026-11-27-004 — لا نختزل التسميات كلها إلى disease IDs

- **التاريخ:** 2026-11-27
- **الحالة:** معتمد ضمن تنقيح الخطة.
- **القرار:** يسبق mapping تحديد نوع المهمة والفئة (محصول، صنف، سليم، مرض، آفة، نقص غذائي، عرض غير محدد). لا تُربط الفئة بمعرف مرض إلا إذا كان ذلك صحيحاً علمياً ومدعوماً بالتسمية الأصلية.
- **الدليل:** سجل `public/models/plant-disease/labels.json` فارغ حالياً، كما أن سجلات النماذج تضم مهاماً وفئات غير مرضية.
- **الأثر:** `research/label-map.json` يوثق mappings المقبولة، والفئات غير القابلة للتعيين تُستبعد أو تعالج بقرار مستقل؛ لا تُدمج لمجرد تشابه الاسم.

## D-2026-11-27-005 — منع تسرب البيانات يتضمن المجموعات والتشابه البصري

- **التاريخ:** 2026-11-27
- **الحالة:** معتمد ضمن تنقيح الخطة.
- **القرار:** لا يكفي فصل الملفات أو أسماء الصور. يلزم group-disjoint حسب المحصول/المصدر، مع فحص SHA-256 والتكرار القريب/القصاصات المتشابهة عبر التقسيمات.
- **الدليل:** بعض التقسيمات السابقة كانت image-level أو تفتقر إلى معرفات نبات/كرمة/موقع/جلسة موثوقة.
- **الأثر:** يضاف اختبار آلي يمنع التداخل الدقيق ويكشف التشابه القريب، وتُوثق الحالات الملتبسة قبل إغلاق البوابة.

## D-2026-11-27-006 — لا اختيار مسبقاً لـ YOLOv8 + SAM أو Cross-Attention

- **التاريخ:** 2026-11-27
- **الحالة:** معتمد ضمن تنقيح الخطة.
- **القرار:** تُعامل هذه الخيارات كمرشحات للمقارنة، لا كاختيارات نهائية. تتم مقارنة تجزئة مباشرة مقابل كاشف مع SAM، ودمج بسيط مقابل Cross-Attention، بعد توافر بيانات مناسبة.
- **الدليل:** لا توجد Gold lesion masks معتمدة حالياً، وتعقيد النموذج لا يثبت تحسناً تلقائياً.
- **الأثر:** اختيار المعمارية لاحقاً بناءً على نتائج قابلة لإعادة الإنتاج، مع المحافظة على baselines والأوزان القائمة.

## D-2026-11-27-007 — معايرة مستقلة وحماية الإنتاج

- **التاريخ:** 2026-11-27
- **الحالة:** معتمد ضمن تنقيح الخطة.
- **القرار:** Temperature Scaling على مجموعة معايرة مستقلة عن الاختبار النهائي. لا يُفعّل أي نموذج إنتاجي ولا يُعدّل `main` أو manifest الإنتاج خلال Phase 0.
- **الدليل:** ضرورة منع تسرب الاختبار إلى المعايرة، وحالة manifest الحالية `enabled=false` و`reviewStatus=candidate`.
- **الأثر:** يبقى التفعيل خارج نطاق هذه المرحلة؛ Phase 5 يتطلب تكافؤ المعالجة واختبار ONNX والجهاز قبل أي ترقية.
