# Dr.Plant Lemon V3 — refined exploratory run (2026-11-25)

- Dataset: Mendeley Data V3, DOI 10.17632/8d9fv6kpt3.3, CC BY 4.0
- Images: 17,586; classes: 18
- Training: resumed from epoch 6, completed through epoch 9; MobileNetV3-Small, 128px, CPU, last two feature blocks fine-tuned
- Best validation accuracy: 71.00%
- Test accuracy: 72.06%; macro-F1: 67.46%
- Test images: 2,638; ONNX checker passed, ONNX Runtime loaded, 100% prediction agreement with PyTorch; max absolute logit difference 0.0003701

## Limitations
Image-level stratified split only; no per-tree/farm/session IDs, so this is not independent external validation. Images are photographed on white backgrounds in Bangladesh, not Syrian field imagery. Dataset labels have not been independently expert-reviewed by the Dr.Plant team. This is exploratory only and must not be promoted as a validated Syrian lemon diagnosis model.
